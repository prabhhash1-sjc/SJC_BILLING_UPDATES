# SJC BILLING SOFTWARE

SJC BILLING SOFTWARE is a desktop billing and invoice management application.

## Current Version

V1.9.4

## Update System

This repository is used for SJC BILLING SOFTWARE update distribution.

The software checks the root `manifest.json` file for available updates.

## Update Components

- Root `manifest.json` – Update information
- GitHub Releases – Patch ZIP files
- SHA-256 verification – Patch integrity verification
- Approved files – Only authorized application files are updated

## Release

Latest stable release:

**SJC BILLING SOFTWARE V1.9.4**

Patch files are distributed through GitHub Releases.

## Important

Do not delete or rename the root `manifest.json` file.

The update ZIP should be uploaded to the corresponding GitHub Release Assets.
